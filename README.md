# Boll & Skoj

A 3D marble-rolling browser game. You are the ball. Stay on the track, collect stars, and spend them on upgrades between courses.

## Play

- **WASD** / arrows — roll (camera-relative: A left, D right)
- **Space** — jump
- **Q / E** or drag — look around
- **Esc** — pause

On a phone, use the on-screen stick and jump button.

## Courses

1. **Kajen** — wide docks, one barge, a slow spinner
2. **Broarna** — beams and jumps (unlock by finishing Kajen)
3. **Fyren** — high wind and fast arms

Stars bank after each run. Open the shop from the menu or the result screen.

## Develop

```bash
npm install
npm run dev
```
